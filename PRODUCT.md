# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Army personnel and cybersecurity experts evaluating and monitoring the cyber reasoning system.

## Product Purpose
An autonomous cyber reasoning system that uses AI to detect and patch vulnerabilities, providing real-time traces and metrics.

## Positioning
Technical but not dense. A highly accessible, UI/UX friendly interface that surfaces deep technical execution details (like live AI traces) without overwhelming the user. 

## Operating Context
Live monitoring of autonomous fuzzing, triage, RCA, and patch generation, particularly during the Indian Army Terrier Cyber Quest 2026.

## Capabilities and Constraints
- **Theming:** Must support both Light and Dark modes nicely.
- **Tech Stack:** React 18, Vite, TanStack Query frontend.
- **Backend Constraints:** Integrates with FastAPI, Semgrep, and AFL++.

## Brand Commitments
Army-themed design system with prominent green accents.

## Evidence on Hand
The dashboard will consume real-time traces and structured metrics (Success Rate, MTTD, MTTR, AI Efficiency) from the running agent pipeline.
